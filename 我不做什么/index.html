我不做什么#

vibe-coding 三不做#

  1. 不做和数据相关的. 爬取抓包等和数据相关的 dirty work 太多, 而且大多数事后只是没有找到合适的方式或者是平台. 例如机票查询助手, 我不需要爬取历史数据获得自己的一个数据库, 这个是缺乏安全感或者是强调控制欲的表现, 我只需要在使用的时候对比一下各个平台然后找出最低价格, 或者是在社交媒体上面找一些经验贴子就可以了. 经验和教训还是太多了. 同理类似的项目还有: 获取国家宏观经济数据, 炒股所需要的专业金融财经数据( os. 这些东西都是专业付费的东西如果希望能做出来就要拿出盈利的专业态度来做, 而不仅仅是 vibe coding 实现的) 以及微信对话助手导出. QQ 对话机器人会是一个有趣的项目. 但是, 储存自己的重要的数据还是很重要的, 例如和重要的人的聊天记录, 自己的人生记录, 行动路径, 旅行地图规划以及出行定位记录(交通酒店景点). 还有旅游回忆录, 事实上也是很有用的记录和经验. 或许 bilibili 和小红书上的穷游助手很有帮助.
  2. 需要大量前端交互逻辑或者是专业知识背景审查的, 在自己陌生领域的不做. 或者是工具本身受限于平台, 也就是使用者的视野太过狭窄的方式不做. 类似于 RPA 自动化控制工具, 微信对话导出助手, 前端交互如互动网页或者是 3D 建模类型工具(需要其他 AI 网站例如 mesh 的使用经验, 或者是 AI 漫剧). 还有就是自动记账这种产品, 没有真正解决自己的痒点, 如果只是记录, 没有让我产生对日常花销流的观察或者是改进控制的想法也是没有用的. 但是 invoice downloader 或许是有用的, 保存个人数据的一个好方法. 相反, 内容为王, 看重长期积累的项目可以做, 例如博客文章.
  3. 造轮子或者是注定被淘汰的底层工具不做. 例如 personal auto-research, 这个是 loop engineering 的简单实现, kimi code 中也有 harness 的实现( /goal 模式), 可以做的是 claude code switcher. 微信自动拜年语句生成, 学习进度追踪打卡( 虽然这个更应该用 ticktack, 但是这里是编程或者控制管理的思路说明啦). 可以做的是追踪情绪或者是潮流的东西, 例如火爆全网的 imsb, 但是不能做实证实验, 例如追踪测试率. 但是可以做具体应用, 例如利用 CV + 运动模式识别实现卧推发力轨迹记录定位矫正评分, 最主要的是高储存效率视频的保存.
